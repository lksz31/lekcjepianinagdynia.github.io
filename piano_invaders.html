🎵 Krok 1 — Ruch pianina
🎹 Oktawa mała  ( c — h )
Nuty oktawy małej = RUCH pianina
Zaśpiewaj lub zagraj nutę małą — pianino wskoczy do odpowiedniej kolumny.
Oktawa mała (c–h) = ruch pianina
Oktawa razkreślna (c¹–h¹) = strzał
Im niższa nuta → lewa kolumna | Im wyższa → prawa kolumna
7 kolumn = c d e f g a h
🎯 Krok 2 — Strzelanie
🎯 Oktawa razkreślna  ( c¹ — h¹ )
Nuty oktawy razkreślnej = STRZAŁ
Każda nuta strzela w potworka z tą samą literą.
⚠ Najpierw stań pod potworkiem, potem strzelaj!
1. Nuta oktawy małej → przesuń pianino
2. Nuta oktawy razkreślnej z tą samą literą → strzał!
